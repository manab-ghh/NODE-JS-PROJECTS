# Todo List API

A simple RESTful API for managing todo tasks built with Node.js, Express, and MongoDB.

## Features
- Create new todos
- View all todos
- View single todo
- Update todos
- Delete todos
- MongoDB database storage

## Prerequisites
- Node.js (v14 or higher)
- MongoDB installed locally or MongoDB Atlas account
